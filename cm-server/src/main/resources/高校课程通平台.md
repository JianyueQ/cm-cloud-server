# 高校课程通平台项目总结

## 一、项目概述

这是一个基于Spring Boot的Web应用程序，主要用于管理校园内的课程、学生、教师以及相关的教学活动。
该项目采用了经典的分层架构，包括表示层、业务逻辑层和数据访问层。后端使用Spring Boot框架，
结合MyBatis进行数据库操作，数据存储在MySQL中。为了提高系统性能，引入了Redis作为缓存层，用于存储高频访问的数据，
比如用户信息和课程详情。同时，我们也使用Redis实现了分布式锁和令牌桶限流算法来处理并发控制和接口限流。
系统主要有三个用户角色：管理员、教师和学生，各自有不同的权限和功能模块。
管理员负责用户管理、课程管理和系统监控；教师可以创建和管理课程、发布资源、进行考勤管理和成绩录入；学生可以选择课程、参与考勤、查看成绩和下载学习资源。
课程管理模块支持教师创建课程并设定容量限制，学生可以根据自己的需求选择课程。考勤系统支持多种考勤方式，如位置定位和数字码签到，并通过WebSocket实现实时通知。成绩管理模块允许教师录入和管理学生成绩，并提供统计分析功能。
系统还集成了阿里云OSS用于存储教学资源文件，使用RabbitMQ处理异步消息，比如聊天消息和系统通知。安全方面，采用JWT进行身份认证，并通过自定义拦截器实现权限控制。

- **核心框架**：Spring Boot

## 五、关键技术实现细节

### 5.1 缓存优化

使用Redis作为缓存层，提高系统响应速度：

1. **热点数据缓存**：课程信息、用户信息等
2. **分布式锁**：防止并发问题
3. **缓存自动管理**：自定义注解实现缓存自动加载和清除

### 5.2 并发控制

1. **Redis令牌桶限流**：防止恶意请求
2. **分布式锁**：解决选课等场景的并发问题
3. **原子操作**：利用Redis保证数据一致性

### 5.3 文件处理

1. **文件存储**：集成阿里云OSS
2. **Excel导入导出**：批量处理学生,教师的账号数据

### 5.4 实时通信

1. **WebSocket**：实现考勤实时通知和聊天功能
2. **RabbitMQ**：处理异步消息和离线推送

### 5.5 安全防护

1. **JWT认证**：无状态认证机制
2. **接口限流**：防止恶意刷接口
3. **单点登录**：实现单点登录功能

## 六、项目亮点

1. **多角色权限体系**：基于角色的权限控制
2. **架构思想**：模块化设计，便于维护扩展
3. **高性能缓存策略**：Redis多级缓存提升系统性能
4. **丰富的交互体验**：WebSocket实现实时通信
5. **完善的监控体系**：系统监控+操作日志追踪
6. **灵活的数据处理**：Excel导入导出，方便批量操作
7. **高安全性设计**：JWT+拦截器实现安全控制
