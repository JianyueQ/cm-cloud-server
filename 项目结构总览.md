## 技术栈对照表

| 层次 | 原单体架构 | 微服务架构 | 说明 |
|-----|-----------|-----------|------|
| 服务注册 | 无 | Nacos | 服务自动注册与发现 |
| 配置中心 | 本地配置 | Nacos Config | 集中配置管理 |
| 负载均衡 | 无 | Spring Cloud LoadBalancer | 客户端负载均衡 |
| API网关 | 无 | Spring Cloud Gateway | 统一入口 |
| 服务调用 | 本地调用 | OpenFeign | RPC调用 |
| 持久层 | MyBatis | MyBatis | 不变 |
| 缓存 | Redis | Redis | 不变 |
| 数据库 | MySQL | MySQL | 不变 |
| 消息队列 | RabbitMQ | RabbitMQ | 不变 |
| 对象存储 | 阿里云OSS | 阿里云OSS | 不变 |

## 数据流向

### 请求流程
```
客户端 → Gateway(8080) → 认证过滤器 → 路由转发 → 目标微服务 → 数据库/缓存
```

### 服务间调用
```
服务A → Feign接口 → Ribbon负载均衡 → Nacos服务发现 → 服务B
```

## 下一步工作

1. **业务代码迁移**
   - 从cm-server将业务逻辑迁移到对应微服务
   - 按业务域划分Controller、Service、Mapper

2. **Feign接口定义**
   - 在cm-api模块定义服务间调用接口
   - 实现服务间通信

3. **网关过滤器**
   - 实现JWT认证过滤器
   - 添加限流熔断策略

4. **配置中心化**
   - 将配置迁移到Nacos
   - 实现动态配置刷新

5. **监控告警**
   - 集成Spring Boot Admin
   - 配置健康检查
